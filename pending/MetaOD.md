## What it is

MetaOD is a meta-learning method for [[Unsupervised Outlier Model Selection]]. The deck cites it as "MetaOD: Automatic Outlier Model Selection", NeurIPS '21, by Zhao, Rossi, and Akoglu. The deck presents it as the answer to "How to Automate OD/OOD Model Selection w/o Labels?" ([[Block 7 Slides]], p. 356). The outline calls it "Meta learning for automating OD/OOD model selection" (p. 354). The slide underlines the name Zhao. Synthesis: the underline marks the course instructor, Yue Zhao.

MetaOD predicts how each candidate model would perform on a new, unlabeled dataset. Then it picks the model with the best predicted performance. The slide title says: "MetaOD: Predict Test Model Perf. Via Meta-Learning" ([[Block 7 Slides]], p. 373).

## Facts

### Offline training: factorize the performance matrix

The input is the historical performance matrix P. P has n datasets as rows and m models as columns, and evaluation on labeled datasets fills it; see [[Unsupervised Outlier Model Selection]], § Problem formulation.

- Challenge 1 is to "Measure Dataset Similarity w.r.t Perf." The slide asks about "similarity by performance?". It lists three ways to get a "Unified embedding w.r.t. performance": matrix factorization, neural net, and "(recent) LLMs" ([[Block 7 Slides]], p. 370).
- MetaOD factorizes P ≈ U · V^T by "Non-negative low-rank matrix factorization/decomposition (i.e., k < m and k < n)" (p. 371).
- U has n rows and k factors. It is the "dataset matrix for data similarity". V^T has k factors and m columns. It is the "model matrix for model similarity" (p. 371).
- A row of U is a dataset embedding. A column of V^T is a model embedding, which the slide marks "(transferable)" (p. 372).

### Online selection: predict performance on X_test

A new dataset X_test gets a test embedding U_test. The predicted model performance is P̂_test := U_test V^T. V^T comes from offline training; the slide calls this step "Transfer knowledge via meta-learning" ([[Block 7 Slides]], p. 373). In the example, the predicted row for X_test is 0.7, 0.3, ..., 0.2, and the slide highlights 0.7 for M_1 (pp. 373, 382).

The slide then asks: "How to get the embedding of the test data?" (p. 373). Synthesis: X_test has no row in P, so the factorization cannot give U_test.

### Challenge 2: predict the dataset embedding U_test

- The question: "Can we train a predictive model f(·) on the historical to predict to test data embedding?" ([[Block 7 Slides]], p. 374).
- Training: a regressor f(·) maps the historical datasets D_1, ..., D_n to U, the dataset matrix "generated by matrix factorization on P" (p. 375).
- Raw datasets cannot go into f directly, because they have "Different # features and # samples" (p. 376).
- The fix: a meta-feature extractor φ ("summarize", "standardize") comes before the regression f, and f outputs U (p. 377). The slide adds: "More recently, using deep learning or LLMs to extract embeddings" (p. 377).
- φ and f train offline "on prior experience (meta-train: D_1, ..., D_n)" (p. 380).
- Prediction: "predict test data embedding by U_test = f(X_test)". Online, X_test goes through the same φ and f (p. 381). Synthesis: the formula leaves out φ; the diagram shows that f takes φ(X_test).
- With U_test predicted, P̂_test := U_test V^T gives the predicted performance of every model in the set (p. 382).

### Meta-features

- "Meta-features: characteristics of a dataset". The examples are the number of samples (n), the number of features (p), the sample mean, the sample median, and "Other data characteristics". The extractor φ turns an "Arbitrary Raw dataset" into meta-features. Its two jobs are to "summarize" and "standardize" ([[Block 7 Slides]], p. 378; repeated on p. 384).
- "Meta-feature extraction: characterize an arbitrary dataset as a 200-element meta-feature vector". The 200 elements are 128 "Statistical features" (statistical characteristics) and 72 "OD features" (OD-related characteristics). The slide marks the OD features "[new]" (p. 379).
- The limitation: "Meta-feature extraction for datasets: handcrafted, heuristic". The open question: "Which statistical features should I use?" (p. 385). MetaOOD answers this with LLM embeddings (below).

### Results

The recap slide lists two results under "Problem Formulation of unsupervised OD model selection (UOMS) by meta-learning" ([[Block 7 Slides]], p. 393):

- Performance: "On avg. the top 18% model from 300+ models".
- Speed: "≤1s for most datasets".

Open point: the slide does not name the method, and it does not give the metric behind "top 18%". Synthesis: the recap follows the MetaOD part, so these results probably describe MetaOD.

The summary table of automated OD/OOD algorithms lists MetaOD (2021) with algorithm selection, discrete hyperparameter optimization, meta-learning, and training-free at test time. It does not list continuous hyperparameter optimization (p. 396). Synthesis: the MetaOD slides show only selection from a fixed model set; they do not show how MetaOD does discrete hyperparameter optimization.

### MetaOOD

MetaOOD is the follow-on method. It replaces handcrafted meta-features with LLM embeddings of datasets and models.

- The deck presents it as "Part 2: Improve Unsupervised Model Selection via LLM-based Data Features": "MetaOOD: Automatic Selection of OOD Detection Models", ICLR '25, by Qin, Zhang, Nian, Ding, and Zhao ([[Block 7 Slides]], p. 383). The outline lists it under "Model Selection by LLMs" (p. 354).
- **LLM-generated data features.** "Standardize data representations via LLMs": OOD dataset descriptions go through an LLM, which outputs a language embedding (p. 386). The example description is CIFAR-10: "Contains images of 10 types of objects, including airplanes, cars, birds, cats, deer, dogs, frogs, horses, ships, and trucks. Each image is a small 32x32 RGB image." (p. 386). The [[k-Nearest Neighbors]] topic holds more facts about CIFAR-10.
- **LLM-generated model features.** "Standardize model representations via LLMs": "OOD model descriptions + raw code" go through an LLM, which outputs a language embedding (p. 387). The example description is Openmax: "Determines a center for each class in the logits space of a model, and then creates a statistical model of the distances of correctly classified inputs. It uses extreme value theory to detect outliers by fitting a Weibull function to the tail of the distance distribution. The activation of the unknown class is used as the outlier score." (p. 387).
- **Training.** LLMs embed the historical datasets and the model set ("Embeddings by LLMs"). A regression f maps these embeddings to the performance matrix (p. 388). Open point: the slide subtitle reads "Training: regressor f(·) to predict dataset embeddings", which repeats MetaOD's subtitle on p. 375. But the diagram on p. 388 and the formula on p. 389 show that f outputs performance, not a dataset embedding.
- **Zero-shot selection.** f takes the test data and one model and outputs a predicted performance, for example 0.7 for Model 1. "[Zero Shot] Iterate over all models in ℳ, choose the one with the highest predicted performance": argmax_{M∈ℳ} f(Emb(X_test), Emb(M)) (p. 389).
- **Paper figure.** Figure 1 of the paper shows the full method (pp. 390-391). Offline, "running m OOD detection methods on n dataset pairs" gives an "m*n Performance Matrix P". A pre-trained language model gives dataset embeddings E^dataset (ψ) and model embeddings E^model (φ). A meta-predictor f learns to map the embeddings to P. Online, the new dataset pair D_new goes through the same language model (ψ) to give E^test. Then f predicts P̂_new,j for each detector, and the selected model is M* = argmax_{M_j∈ℳ} P̂_new,j. Notation: the figure writes the matrix as m*n and uses φ for the model embedding. The MetaOD slides write P ∈ ℝ^(n×m) and use φ for the meta-feature extractor.
- **Overhead.** "Model selection overhead negligible to the actual OOD detection fitting on the image datasets" (p. 392). Figure 7, "Runtime of MetaOOD vs. selected OOD detector", splits the MetaOOD time into data embedding generation and model selection with data embedding. It compares this with the time to train the selected model. The differences are 22.3 s (CIFAR10-CIFAR100), 46.2 s (CIFAR10-SVHN), 37.8 s (CIFAR100-CIFAR10), and 83.0 s (CIFAR100-SVHN) (p. 392). Synthesis: in each "dataset pair", one dataset probably supplies the in-distribution data and the other the OOD data; the slides do not say this.
- The summary table lists MetaOOD (2025) with algorithm selection, meta-learning, and training-free at test time, and with no hyperparameter optimization (p. 396).
- The recap's third step, "Language embeddings for datasets and models", shows the same vector as the meta-feature picture (n, p, 0.7, 0.65) with the label "Language Embeddings" (p. 395).
