## Definition

Classical machine learning is the set of methods that CSCI 566 teaches before neural networks: trees and their ensembles, nearest neighbors, and clustering. This page gathers them; each linked topic holds the claims and their citations.

## Explanation

### Trees

- [[Decision Trees]]: A classical ML classifier that tests one feature at each node and predicts the majority class at a leaf.

### Instance-based methods

- [[k-Nearest Neighbors]]: k-nearest neighbors (kNN) stores the training set and labels a new point by majority vote over its k nearest training points under a chosen distance function.

### Unsupervised learning

- [[Clustering]]: clustering is the unsupervised task of grouping unlabeled observations by their inputs alone.
